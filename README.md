# Image Converter

A simple browser-based image converter made by **red0x**.

It lets you upload a JPG or PNG image, preview it, convert it to the other format, and download the converted image.

https://red0x-106.github.io/Image-converter/

## What is Image Converter?

Image Converter is a website for converting images between JPG and PNG.

The main idea was to make a small tool where everything happens directly on the website. You can select an image, see it before converting, choose the format, and download the result.

## How to Use It

The Image Converter runs in a web browser, so there is nothing to install.

1. Open the Image Converter website.
2. Upload a JPG or PNG image.
3. Check the image in the preview.
4. Choose the format you want to convert it to.
5. Convert the image.
6. Download the converted image.
7. Use the clear button if you want to start again.
